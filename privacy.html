Privacy Policy

Last updated September 2026

Short version

This website does not use cookies, does not run analytics, and does not have accounts. The Aerini application does not send telemetry of any kind. Everything below explains exactly what small amount of network activity does happen, and why.

What this website collects

This site stores nothing itself: no account system, no sign-up form, no comment section, and no server-side database behind it. Nothing you type or click here is saved by us. Loading the page does trigger a few requests to third-party services that see your IP address — Google Fonts, GitHub's API, and, on the Pricing page, Polar's checkout script. See the next section for details.

Cookies and local storage

This site sets no cookies. It does not use your browser's local storage either. Nothing here is used to recognize you on a return visit. The one exception to the no-cookies statement is the Pricing page, where clicking "Buy commercial license" opens a checkout window run by Polar (see below) — that window is Polar's, not ours, and Polar's own cookie and privacy practices apply to it, not this policy.

Requests this website makes to other services

Loading this page triggers a small number of requests to services we do not control:

  • Google Fonts. The page text uses the Inter and JetBrains Mono typefaces, loaded from Google's font CDN. Google's servers see the IP address and browser making that request, the same as any font or image loaded from a third-party CDN. We don't control what Google does with that request; see Google's own privacy documentation if you want details.
  • GitHub's public API. The "Get Aerini" button checks GitHub's releases API to find the correct installer for your operating system, and the platform picker does the same for each platform. It is a public, unauthenticated endpoint. It sends nothing about you beyond a standard HTTP request; GitHub sees your IP address the way any site you visit does.
  • Polar. The Pricing page loads Polar's checkout script, served from the jsDelivr CDN (cdn.jsdelivr.net), which sees your IP address and browser the way any CDN does. Polar is the payment processor used for commercial licenses. It only runs when you visit that page, and it only opens a payment window if you click "Buy commercial license." If you complete a purchase, your name, email, and payment details are collected and processed by Polar as the merchant of record — not stored on this site. See Polar's privacy policy for how they handle that data.

If this site is hosted on GitHub Pages or a comparable static host, that host may keep ordinary web server access logs (IP address, requested page, timestamp) as part of normal operation. We don't add any tracking on top of that, and we don't have a separate analytics dashboard for this site.

The Aerini application

The website and the desktop application are different things, and this section is about the app. Aerini makes no telemetry calls, no analytics calls, and no automatic update pings. Workflows, run history, and credentials stay on your machine and are never sent anywhere by Aerini itself.

Two fixed exceptions, by design: the app loads the Inter typeface from Google Fonts over HTTPS at startup, and Settings → About has a "Check for Updates" button that fetches the latest GitHub release's update manifest only when you click it. If you then choose Install and restart, the app downloads the signed update from GitHub. Beyond that, any outbound connection comes from workflow nodes you build yourself, such as an HTTP request node hitting an API you configured, or an AI node calling a provider you chose and gave a key to. For the full technical breakdown, see the security documentation.

Data retention

We have nothing to retain. There is no account data, no usage history, and no analytics database tied to this site or the app.

Children's privacy

This site and the app are not directed at children and are not designed to collect information from anyone, regardless of age.

Changes to this policy

If what this site or the app does ever changes in a way that affects this page, we'll update it here and change the date at the top.

Contact

Questions about this policy: support@aerini.org.
